# 升級商店：新鍋子

## 一句話說明

在開店頁的「升級商店」可以花 800 元買一個「新鍋子」，買了之後從當天到第 5 天，每天的產能上限從 80 份變成 90 份。

## 玩家可以做什麼（操作）

1. 在「開店」頁，**還沒按「開始營業」之前**，按上方工具列的「升級商店」按鈕。
2. 畫面打開一個小面板，顯示：
   - 商品名稱：新鍋子
   - 價格：800 元
   - 效果：每天產能 80 → 90 份，從今天到第 5 天都有效
   - 目前資金
   - 「購買」按鈕、「關閉」按鈕
3. 按「購買」→ 扣 800 元，面板顯示「已購買」，產能提示變成「合計份數 ?／90」。
4. 按「關閉」→ 關掉面板，什麼都不買。

## 規則（用數字寫清楚，不要寫「適量」「一些」）

| # | 規則 |
|---|---|
| R1 | 新鍋子價格 **800 元**。 |
| R2 | 買了之後，每天所有菜合計最多可備 **90 份**（沒買是 80 份）。 |
| R3 | 效果從**購買當天**開始，一直到**第 5 天**都有效。 |
| R4 | 只能在某一天**開店前**（還沒按「開始營業」）購買。營業中、打烊報表畫面、五天結算後都**不能**買，「購買」按鈕顯示為不能按。 |
| R5 | 每一場**最多買 1 次**。買過之後面板顯示「已購買」，「購買」按鈕不能按。 |
| R6 | 現有資金 **< 800 元**時不能買，「購買」按鈕不能按，並顯示「資金不足（需要 800 元，目前 X 元）」。 |
| R7 | 按下「購買」的當下就從資金扣 800 元。之後當天的「備貨＋宣傳不能超過現有資金」檢查，用的是扣完之後的資金。 |
| R8 | 800 元購買費**不算進**當天打烊報表的備貨、宣傳或淨利（所以不影響第 5 天「淨利 800 元以上」任務的判定），只會讓資金減少。 |
| R9 | 正式模式和跳關練習模式都能買，規則相同。 |
| R10 | 不存檔：重新整理網頁、按「重新開始」或「開始練習」開新的一場，都回到**沒買過、產能 80 份**的狀態。 |

## 不做什麼（範圍外）

- 不做其他商品（招牌燈、冰箱），商店裡只有新鍋子一樣。
- 不能退貨、不能賣回。
- 不存檔、不連網。
- 不改試算工具 `npm run simulate`：試算仍然以產能 80 份計算，不支援新鍋子。
- 不改規則書 `docs/RULES.md` 的既有內容，也不改任何既有規則（成交、收支、口碑、任務、說話、倉庫盤點）。
- 不改 `web-lab/scripts/check-rules.mjs`、`web-lab/scripts/simulate.mjs`。

## 會影響到的既有規則

| 既有規則 | 現在 | 影響 |
|---|---|---|
| 每天要做的決定：所有菜合計最多 80 份（`config.js` 的 `DAILY_CAPACITY`） | 固定 80 | 買了新鍋子之後，這一場的上限變成 90；`DAILY_CAPACITY` 本身保持 80，當作「沒買時」的預設值 |
| 備貨成本＋宣傳費不能超過現有資金（`validatePlan.js`） | 用當下資金檢查 | 用扣掉 800 元之後的資金檢查 |
| 一天的狀態（`engine.js` 的 `newGame`、`simulateDay`） | 記錄 day、cash、stars、history | 多記錄「這一場是否已買新鍋子」，`simulateDay` 要把它帶到隔天 |
| 每日任務第 5 天「淨利 800 元以上」 | 用當天淨利判定 | 不受影響（見 R8） |

## 驗收案例（至少 3 個：輸入 → 預期結果）

| # | 輸入 | 預期結果 |
|---|---|---|
| A1 買到 | 官方客人包、正式模式第 1 天開店前，資金 2,000 元，按「升級商店」→「購買」 | 資金變成 **1,200 元**；面板顯示「已購買」；開店頁的份數提示顯示「／90」 |
| A2 產能變 90 | 承 A1，招牌鍋貼備 85 份 | 可以按「開始營業」，沒有錯誤訊息 |
| A3 上限仍有 | 承 A1，招牌鍋貼備 91 份 | 出現錯誤「今天合計 91 份，超過每日產能 90 份」，不能開始營業 |
| A4 沒買照舊 | 沒買新鍋子，招牌鍋貼備 85 份 | 出現錯誤「今天合計 85 份，超過每日產能 80 份」 |
| A5 不能買第二次 | 承 A1，再打開升級商店 | 顯示「已購買」，「購買」按鈕不能按，資金維持 1,200 元 |
| A6 效果持續 | 第 1 天買了新鍋子，玩到第 3 天開店前 | 份數提示仍是「／90」，備 90 份可以開始營業 |
| A7 錢不夠 | 資金 < 800 元時打開升級商店（例如用程式直接對 `buyPot` 傳入 cash 799 的狀態） | 「購買」按鈕不能按、顯示「資金不足（需要 800 元，目前 799 元）」；`buyPot` 回傳失敗，資金不變 |
| A8 營業中不能買 | 按下「開始營業」後、打烊報表出現前，打開升級商店 | 「購買」按鈕不能按 |
| A9 不存檔 | 買了之後重新整理網頁 | 回到第 1 天、資金 2,000 元、份數提示「／80」、商店顯示可購買 |
| A10 不改壞 | 在 `web-lab` 執行 `npm run check` | 原本 72 條**全部 PASS** |
